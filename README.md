# Embryo：从果蝇到人的发育式认知架构

一个分层发育的认知系统原型——不是预训练好的大模型，是一个小东西从反射开始，分层长出大脑。

## 架构（L0-L10）

```
┌─────────────────────────┐
│  L10: 前额叶（可学习）    │  ← 任务判断/上下文整合（婴儿状态起步）
├─────────────────────────┤
│  L9: 回放（睡眠重放）     │  ← 只强化抽象模块，不碰具体反射
├─────────────────────────┤
│  L8: 上下文调制（可学习）   │  ← 动态增益（婴儿状态起步）
├─────────────────────────┤
│  L7: 记忆巩固            │  ← 突触固化+选择性遗忘（只忘没激活的）
├─────────────────────────┤
│  L6: 语言通道            │  ← 听懂指令（上/下/左/右）
├─────────────────────────┤
│  L5: 内部模拟（前向模型）  │  ← 在脑子里试动作，不真撞
├─────────────────────────┤
│  L4: 空间记忆（海马体）   │  ← 记住食物在哪，没线索时往那走
├─────────────────────────┤
│  L3: 习惯层（蘑菇体）     │  ← 视觉cue→动作，Hebbian学习
├─────────────────────────┤
│  L2: 感觉编码（KC）       │  ← 稀疏编码，把视觉+语言变成神经活动
├─────────────────────────┤
│  L1: 先天趋性（反射弧）   │  ← 朝气味走、饿了找食（硬编码）
├─────────────────────────┤
│  L0: 身体+世界           │  ← 2D grid、4方向动作、能量条
└─────────────────────────┘
```

## 学习规则

只有一个底层模式：**本地共激活 + 全局调质**

```
对任意突触 i→j：
  Δw_ij = lr · σ_j · s_i · DA
  # σ_j = 突触后激活
  # s_i = 突触前激活
  # DA = 多巴胺（吃到食物+1，撞墙-0.3，otherwise 0）
```

没有反向传播、没有TD error、没有策略梯度。只有Hebbian + eligibility trace。

## 运行

```bash
python embryo.py
```

从checkpoint继续训练（调参用）：
```python
from embryo import run
run(n_steps=5000, 
    resume_mb='checkpoints/mb_final.npz',
    resume_hip='checkpoints/hip_final.npy',
    resume_fm='checkpoints/fm_final.npy')
```

## 关键决策与数据对比

### 决策1：L7记忆巩固——只对长期不激活的突触衰减

| 方案 | 效果 | 结论 |
|---|---|---|
| 全局衰减（每步所有突触都衰减） | 找食提升从89%降到28% | ❌ 把学的东西都抹掉了 |
| 只对没激活的突触衰减 | 找食提升84% | ✅ 不破坏基线，还能遗忘 |

**结论**：不是所有突触都衰减，只有长期不激活的才衰减。已经学过的不衰减。

### 决策2：L9回放——只强化抽象模块，不碰具体反射

| 方案 | 吃食物 | 饿死 | 听懂指令 | 结论 |
|---|---|---|---|---|
| 无回放 | 202个 | 55次 | 20% | 基线 |
| 回放碰蘑菇体+L10 | 203个 | 57次 | 36% | ❌ 听懂提升但找食冲乱了 |
| 回放只碰L10 | 279个 | 47次 | 31% | ✅ 吃得多、死得少、听懂提升 |

**结论**：回放是巩固抽象概念（任务判断、记忆索引），不是巩固具体的感觉-动作反射。具体反射靠日常Hebbian就够了。

### 决策3：L10前额叶——从硬编码改成可学习网络（婴儿状态起步）

| 方案 | 吃食物 | 饿死 | 听懂指令 | 结论 |
|---|---|---|---|---|
| 硬编码if判断 | 785个 | 11次 | 30% | 凑数版，效果好但不是真学习 |
| 可学习网络（婴儿起步） | 279个 | 47次 | 31% | 真学习，初始没作用，慢慢长大 |

**结论**：硬编码是"占位符"，可学习网络才是真的。初始权重很小（婴儿状态），随着训练慢慢长大。

### 决策4：L10学习速率——不能拔苗助长

| lr | 效果 | 结论 |
|---|---|---|
| 0.05 | 279食物/47饿死 | 慢但稳 |
| 0.08 | 279食物/47饿死 | 中等，稳定 |
| 0.15 | 191食物/59饿死 | 太快，冲乱了 |

**结论**：L10长得太快会冲乱，慢一点稳一点。就像婴儿发育——不能拔苗助长。

### 决策5：语言偏置权重——按饥饿度动态平衡

| 方案 | 吃食物 | 饿死 | 听懂指令 | 结论 |
|---|---|---|---|---|
| 固定权重6.0（太听指令） | 203个 | 47次 | 78% | ❌ 太听指令，不找食物 |
| 固定权重3.0（听指令不够） | 212个 | 47次 | 41% | ❌ 听指令不够 |
| 饥饿度动态平衡 | **609个** | **25次** | 55% | ✅ 不饿听指令，饿了找食物 |

**公式**：`language_weight = 2.0 + 4.0 * energy`（energy从0到1）
- energy=1（不饿）：权重6.0 → 听指令优先
- energy=0（饿了）：权重2.0 → 找食物优先

**结论**：不是固定权重，而是根据内部状态动态平衡。就像人——不忙的时候听别人说话，饿的时候先找吃的。

### 决策6：顺序bug——先set_command再get_input

| 方案 | 听懂指令 | 结论 |
|---|---|---|
| 先get_input再set_command | 29% | ❌ 刚收到指令那一步，还是上一个指令 |
| 先set_command再get_input | 77% | ✅ 指令立即生效 |

**结论**：小bug，影响很大。刚收到指令那一步，必须让虫子立刻听到新指令。

## 当前最优参数

| 参数 | 值 | 说明 |
|---|---|---|
| L3 lr | 0.15 | 蘑菇体学习速率 |
| L3 trace_decay | 0.85 | eligibility trace衰减 |
| L7 base_decay | 0.99999 | 只对没激活的突触衰减 |
| L7 consolidation_threshold | 20 | 激活20次后开始固化 |
| L10 隐藏层 | 6→8→5 | 前额叶加隐藏层（非纯线性） |
| L10 lr | 0.25 | 前额叶学习速率 |
| L10 trace_decay | 0.95 | 前额叶eligibility trace衰减 |
| L10 输出权重 | 0.5 | L10对决策的影响倍数 |
| L8 lr | 0.06 | 上下文调制学习速率 |
| L9 回放频率 | 每1000步 | 睡眠重放 |
| L9 回放次数 | 正16+负6 | 正样本:负样本 = 3:1 |
| L9 回放多巴胺 | 正0.5/负-0.4 | 正强化正确，负抑制错误 |
| 语言权重 | 3.0+4.0*energy | 按饥饿度动态平衡 |
| 指令方向放食物 | 每200步 | 听指令就有奖励 |

## 验证结果（当前版本，seed=42，200000步）

| 指标 | 数值 |
|---|---|
| 吃食物总数 | 1525个 |
| 饿死次数 | 546次 |
| 听懂指令 | 87.7%（877/1000） |
| 找食提升 | 18.4%（69.0步→56.3步） |

> 500000步全量验证结论：每100k段新增饿死288/257/257/267/268（速率不降，累计1337次，≈24%死亡率）；听懂指令率100k后停滞在86-87%（0.877→0.869→0.865→0.868）。200k是性价比最优断点，继续训练只增加饿死、无性能增益。
