Embryo 发育式认知架构

从果蝇级反射开始，分层长出大脑
L0
身体：World（15×15网格，食物、墙、线索、能量）
↑ 感官输入 ↓ 动作输出
L1
先天反射：气味趋性（闻到食物气味就往那走）
L2
感觉编码：视觉（4方向）+ 语言（4词）→ KC稀疏投影（500神经元，5%活跃）
L3
习惯：蘑菇体（Hebbian学习 + 多巴胺调制，无critic、无反向传播）
↕ 平行通路
L4
海马体：空间记忆地图（记食物位置，没线索时往记忆强的地方走）
L5
前向模型：内部模拟（在脑子里试动作，预测结果）
L6
语言通道：4个词（上/下/左/右），听懂指令
↕ 调制信号
L7
记忆巩固：突触固化（反复激活→可塑性降低→长期记忆）+ 选择性遗忘
L8
上下文调制：临时调节KC兴奋性（不改权重，任务切换时调灵敏度）
L9
回放：睡眠重放（定期重放成功经历，强化浅层连接）
↓ 输出
决策
动作选择：气味 + 习惯 + 空间记忆 + 前向模拟 + 语言指令 + 噪声 → argmax → 移动

处理/学习

决策输出
核心设计原则：
1. 纯Hebbian + 多巴胺调制：没有critic、没有TD error、没有反向传播
2. 模块化浅层：每个模块都是1-2层可学习，不堆深层网络
3. 专门通路：视觉、嗅觉、语言各走各的，到决策层才汇合
4. 先天+后天：通路结构是基因写死的，具体连接强度是学出来的
5. 发育式：从反射开始，逐步长出更高级的模块
